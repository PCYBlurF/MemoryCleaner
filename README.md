# 内存清理工具 MemoryCleaner

Windows 内存清理小工具：实时监控内存使用率，一键裁剪进程工作集释放物理内存。托盘图标实时显示使用率数字（颜色随占用冷→暖渐变），支持自动清理与定时清理。

## ✨ 特性

- 📊 **实时监控**：图形界面显示总内存/已用/可用、使用率进度条（冷→暖渐变着色）、占用最高的 15 个进程
- 🧹 **一键清理**：调用 `EmptyWorkingSet` 将当前会话进程的工作集写回页面文件，安全可逆，普通权限即可运行
- 🎨 **托盘图标**：圆角光泽方形 + 白色大数字（带描边，高对比度），数字实时显示使用率；颜色冷蓝 → 青 → 黄橙 → 暖红随占用平滑渐变
- 🖱️ **托盘右键菜单**：
  - 打开主界面 / 立即清理 / 退出
  - **清理时间间隔**：5/10/15/30/45/60/90/120 分钟（定时清理）
  - **满 XX% 清理**：50~95% 阈值（自动清理，标题动态显示当前阈值）
- 💾 **设置记忆**：自动清理/定时清理的勾选状态、阈值、间隔自动持久化（注册表），下次启动自动恢复
- 🚀 **开机自启**：最小化到托盘静默运行（C# 启动器，避免杀毒软件对脚本启动的误报）
- 🔁 **单实例友好**：程序已在托盘运行时，再次双击快捷方式会直接弹出主界面

## 📦 使用

1. 下载最新 [Release](https://github.com/PCYBlurF/MemoryCleaner/releases) 中的 `MemoryCleaner.zip`
2. 解压后双击 **`MemoryCleaner.exe`**（推荐）或 `MemoryCleaner.bat` 启动
3. 或直接双击 `MemoryCleaner.ps1` 所在文件夹内的启动器

## ⚙️ 工作原理

调用 `EmptyWorkingSet` API 将各进程的工作集（物理内存页）裁剪回页面文件，这是 Mem Reduct 等内存清理工具的标准做法：

- ✅ 释放**物理内存（RAM）**：任务管理器"内存"列立即可见
- ✅ 安全可逆：程序需要数据时自动从页面文件换回，不丢数据
- ⚠️ 不清理**虚拟内存**：虚拟地址空间按需提交，不需要也不应该被"清理"（虚拟内存占用短暂增加是换页的正常现象）

## ❓ 常见问题

**开机自启没生效？**
注册表项位于 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`（值名 `MemoryCleaner`）。若被杀毒软件拦截 exe → powershell 的启动行为，请将文件夹加入杀毒软件信任区。

**双击快捷方式没反应？**
程序已在运行时，双击会弹出已运行实例的主界面（单实例模式）；若完全没反应，检查进程是否被杀毒软件拦截。

**为什么"清理"后内存又涨回去了？**
正常现象——空闲内存会被 Windows 用于缓存，程序需要时自动回收，这是现代操作系统的内存管理策略。本工具在内存吃紧时可快速腾出物理内存。
